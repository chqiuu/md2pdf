## 一、项目概述

### 1.1 核心功能

Markdown 文件 → PDF，选择不同样式模板，支持 AI 生成模板 + 手动微调。

### 1.2 项目定位

小而美的独立工具，Web 界面先行，支持 CLI 后续扩展。

---

## 二、技术架构

### 2.1 技术栈

| 组件 | 技术选型 |
|------|---------|
| **运行环境** | Node.js |
| **MD 解析** | markdown-it |
| **代码高亮** | highlight.js |
| **PDF 渲染** | Playwright |
| **Web 界面** | 原生 HTML + CSS + JS |
| **AI 服务** | MiniMax（可配置其他 Provider） |

### 2.2 项目结构

```
md2pdf/
├── src/
│   ├── index.js              # 主入口
│   ├── parser.js             # MD → HTML
│   ├── renderer.js           # HTML → PDF (Playwright)
│   ├── ai-template.js        # AI 生成模板
│   └── template-tuner.js    # 手动微调
├── web/                      # Web 界面
│   ├── index.html
│   ├── app.js
│   └── styles/
├── templates/                # 预设模板 + 用户保存的模板
│   ├── academic.css         # 学术论文风
│   ├── modern.css          # 简洁现代风
│   ├── ebook.css           # 电子书风
│   └── minimal.css         # 极简风
├── ai-providers/            # AI 服务提供商
│   ├── minimax.js
│   ├── kimi.js
│   └── index.js             # Provider 统一接口
├── package.json
└── README.md
```

|------|------|--------|

## 四、模板系统

### 4.1 预设模板

| 模板 | 风格 |
|------|------|
| academic.css | 学术论文风格，正式简洁 |
| modern.css | 简洁现代风 |
| ebook.css | 电子书风格 |
| minimal.css | 极简风格 |

### 4.2 模板结构

每个模板为独立 CSS 文件，包含：

```css
/* 模板示例 */
:root {
  --font-main: "Noto Serif SC", "Source Han Serif CN", serif;
  --font-code: "Fira Code", monospace;
  --font-size: 12pt;
  --line-height: 1.6;
}

body {
  font-family: var(--font-main);
  font-size: var(--font-size);
  line-height: var(--line-height);
}

/* 代码块 */
pre {
  background: #f5f5f5;
  padding: 1em;
  border-radius: 4px;
}

/* 分页控制 */
h1, h2, h3 {
  page-break-after: avoid;
}
table, pre {
  page-break-inside: avoid;
}

/* 页眉页脚 */
@page {
  size: A4;
  margin: 2cm 2.5cm;
}
```

### 4.3 用户保存的模板

用户通过 Web 界面微调后的模板会保存到 `templates/` 目录，可在后续直接使用。

## 五、AI 服务设计

### 5.1 配置文件

```json
{
  "provider": "minimax",
  "apiKey": "your-api-key",
  "baseUrl": "https://api.minimax.chat/v1",
  "model": "MiniMax-Text-01"
}
```

### 5.2 使用方式

```bash
# 指定 AI 配置
md2pdf --ai-config ./ai-config.json input.md -o output.pdf

# 或通过环境变量
export MD2PDF_AI_PROVIDER=minimax
export MD2PDF_AI_API_KEY=your-key
```

### 5.3 内置 Provider

| Provider | 状态 |
|----------|------|
| MiniMax | ✅ 内置 |
| Kimi (Moonshot) | ✅ 内置 |
| 文心一言 | 🔜 后续支持 |
| 通义千问 | 🔜 后续支持 |
| OpenAI | 🔜 后续支持 |

### 5.4 Provider 扩展接口

```javascript
// ai-providers/minimax.js
module.exports = {
  name: 'minimax',
  async generate(prompt, config) {
    // 调用 MiniMax API
  }
};
```

## 六、交互流程

### 6.1 基础转换流程

```
上传 MD 文件 → 选择模板 → 实时预览 → 导出 PDF
```

### 6.2 AI 生成模板流程

```
输入需求描述 → AI 生成 CSS 模板 → 实时预览 → 手动微调 → 导出 PDF
```

### 6.3 保存模板流程

```
选择/上传 MD → 微调样式 → 保存模板 → 输入模板名称 → 保存到 templates/
```
