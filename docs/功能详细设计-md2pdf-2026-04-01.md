# md2pdf 功能详细设计

## 一、整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        Web 界面 (HTML/CSS/JS)                │

│  文件区    │    编辑区    │    预览区    │    控制面板        │

      ▼            ▼             ▼                 ▼

│                     Node.js 服务层                           │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐   │
```

## 五、API 设计（CLI 模式）

### 5.1 命令行接口

```bash
# 基本转换
md2pdf input.md -o output.pdf

# 指定模板
md2pdf input.md -t academic -o output.pdf

# 指定 AI 配置
md2pdf input.md --ai-config ./ai.json -o output.pdf

# 列出模板
md2pdf --list-templates

# AI 生成模板
md2pdf --generate-template "学术论文风格" -o my-template.css

# 启动 Web 服务
md2pdf --serve --port 3000
```

### 5.2 Node.js API

```javascript
const { md2pdf } = require('md2pdf');

// 基本转换
await md2pdf.convert('input.md', { output: 'output.pdf' });

// 自定义模板
await md2pdf.convert('input.md', {
  output: 'output.pdf',
  template: 'modern',
  css: customCSS
});

// AI 生成模板
const css = await md2pdf.generateTemplate('简洁现代风格', {
  provider: 'minimax',
  apiKey: 'your-key'
});
```

### 7.2 水印实现

```javascript
// Playwright 水印实现
async function addWatermark(page, options) {
  const { type, content, position, opacity, angle } = options;

  const watermarkHtml = type === 'text'
    ? `<div class="watermark">${content}</div>`
    : `<img src="${content}" class="watermark">`;

  await page.evaluate((html, opacity, angle) => {
    const style = document.createElement('style');
    style.textContent = `
      .watermark {
        position: fixed;
        top: 50%;
        left: 50%;
        transform: translate(-50%, -50%) rotate(${angle}deg);
        opacity: ${opacity};
        font-size: 48px;
        color: rgba(0,0,0,0.1);
        pointer-events: none;
        z-index: 9999;
      }
      .watermark img { max-width: 200px; }
    `;
    document.head.appendChild(style);
    document.body.insertAdjacentHTML('beforeend', html);
  }, watermarkHtml, opacity, angle);
}
```

## 八、目录生成功能

### 8.1 目录生成规则

| 规则 | 说明 |
|------|------|
| 提取依据 | H1、H2、H3 标题 |
| 层级关系 | H1 为一级，H2 为二级，H3 为三级 |
| 页码获取 | 通过 Playwright 获取每标题的实际页码 |
| 位置 | 可选：文前（默认）或文后 |

### 8.2 目录生成流程

```
解析 MD 内容 → 提取标题列表 → 渲染 PDF（隐藏目录） → 获取每标题页码 → 生成目录 HTML → 插入 PDF
```

### 9.2 批量转换配置

| 配置项 | 说明 |
|--------|------|
| 文件选择 | 多个 MD 文件或整个文件夹 |
| 统一模板 | 所有文件使用相同模板 |
| 或单独模板 | 每个文件可选择不同模板 |
| 输出目录 | 可指定输出目录 |
| 文件命名 | 原文件名 / 自定义前缀 / 时间戳 |
| 错误处理 | 跳过错误 / 停止转换 / 重试 |

### 9.3 批量转换 API

```javascript
// 批量转换
const results = await md2pdf.batchConvert(files, {

  outputDir: './output',
  onProgress: (current, total, file) => {

  }

  errors: [
```

### 10.2 字体加载策略

```javascript
// fonts.json - 字体配置
{
  "fonts": [
    {
      "name": "Source Han Serif SC",
      "family": "SourceHanSerifSC",
      "file": "SourceHanSerifSC-Regular.otf",
      "weight": "normal",
      "style": "normal"
    }
  ]
}

// 启动时加载字体
async function loadFonts() {
  const fontConfig = require('./fonts.json');
  for (const font of fontConfig.fonts) {
    await app.loadFont({
      families: [font.family],
      fontPath: path.join(__dirname, 'fonts', font.file)
    });
  }
}
```

### 10.3 字体使用优先级

```
用户指定字体 → 模板内置字体 → 系统fallback字体
```

### 10.4 字体文件管理

```
md2pdf/
└── fonts/
    ├── fonts.json           # 字体配置清单
    ├── SourceHanSerifSC-Regular.otf
    ├── SourceHanSansSC-Regular.otf
    └── ...
```

**注意**：字体文件较大（单文件 10-20MB），考虑：
- 首次使用时下载
- 提供字体包下载入口
- 压缩字体包（子集化，只包含常用汉字）

### 11.1 CLI 更新

```bash
# 基本转换
```
